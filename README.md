# RoveLighting
Embedded software libraries for WS8212 lighting strips, developed for use with Arduino.
########################################################################################################################
## Usage
This library is a wrapper around the Adafruit_NeoPixel library that handles rendering text, images, and animations on
LED arrays. For generic linear light strips, it is probably better to use the NeoPixel library by itself.

This repo also contains tools for converting images and text into raw C++ arrays for usage by the library.

## Dependencies
- [Adafruit_NeoPixel](https://github.com/adafruit/Adafruit_NeoPixel.git)
